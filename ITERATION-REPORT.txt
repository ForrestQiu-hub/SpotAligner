------------------------------------------------------------------------
一、开发历程 / How it was built
------------------------------------------------------------------------

 1. 距离对齐:一个单声道对象、一个距离、一个声速,输出 = 输入延迟「距离 ÷ 声速」。
    Distance alignment: one mono object, one distance, one speed of sound.

 2. 从延时器变成声像器:加入点话筒角度与主话筒制式 —— 点话筒的左右分配不是一个音量旋钮;
    输入总线改成立体声,内部再把 L+R 相加成那一个对象。
    From a delay to a panner: the spot angle and the array technique arrive; the input bus
    becomes stereo and is summed internally into the one object.

 3. 几何与线索模型抽成四个无依赖头文件,从此一切都能脱离宿主被测试。
    The physics moves into four dependency free headers, so everything can be tested headless.

 4. 制式表与最大拾音角:最大拾音角 ≠ 话筒指向角;时间差阵列有闭式解
    sin(SRA/2) = 声速 × 1.5 ms ÷ 间距,它复现了已发表的 AB 表。
    Technique table and recording angle: the recording angle is not the microphone angle.

 5. 像场位置与畸变:间距型在覆盖角之外饱和,指向型继续扩张。
    Image position and distortion: a spaced array saturates, an aimed one keeps expanding.

 6. 单声道/立体声轨道检测:不足两个声道就原样通过并在面板说明,无需重载。
    Mono and stereo track detection: fewer than two channels means pass through and say so.

 7. 德卡树的中置话筒真的参与运算:独立延时线、等量送入左右,并因此稀释左右线索。
    The Decca Tree centre microphone is really in the audio path and dilutes the outer cues.

 8. 读数架构改写:控制器用与音频相同的纯函数算好、发布成只读参数、视图只解析标签文本 ——
    显示与音频从此不可能给出两个不同答案。
    Readouts rewritten: the controller publishes what the audio uses; views only parse label text.

 9. 强度差:大间距、近距离时 1/r 与时间差都要算,两者方向相反且互补。
    The intensity difference of the 1/r law is in the model, alongside the time difference.

10. 制式从紧身衣变成预设:三项都可改,每个制式只提供它真正会用的选项,改离标准值标出 edited。
    A technique became a preset: everything stays editable, and geometry drift is marked.

11. 界面:黑金配色、可拖动的扇形图、读数区、格式面板,窗口高度 420 → 362。
    The panel: palette, draggable display, readouts, format panel.

12. 验证设施:无头测试、契约检查、布局检查(含父容器层级)、验证器、状态版本链 v1 → v10。
    Verification: headless suites, contract and layout checks, the validator, state versions.

13. 分发:一键安装脚本、单文件 zip、五语 README、厂商改名为 Forrest's Plug-ins。
    Distribution: one click install, a single zip, five languages, vendor renamed.

二、修正记录 / Corrections
------------------------------------------------------------------------

早期 / Early
 E1. 颜色写成 #AARRGGBB(VSTGUI 要 #RRGGBBAA),且漏了 <control-tags> 表 ⇒ 界面一片空白。
     Colours written the wrong way round and a missing tag table.
 E2. CView::setVisible() 不触发重绘,绘制中请求重绘会被丢弃 ⇒ 自定义视图只在 onIdle 改状态。
     setVisible() does not repaint, and a repaint asked for from inside a paint is dropped.
 E3. 延时读数不跟随高度:重算用了一张手写的参数清单 ⇒ 改为除读数自身以外一律重算。
     The delay readout ignored the heights because the trigger list was written by hand.
 E4. 零散编译问题:str16BufferSize 不能加限定、辅助函数在定义前被调用、编辑残留导致括号失衡、
     LINK1104 只是宿主还占着 DLL。
     Small build ones: a qualified macro, a forward reference, a leftover brace, a held DLL.

中期与近期 / Middle and recent
 2.1  单声道检测永远报 0:与自己的默认值比较 ⇒ 改为与上次真正上报的值比较。
 2.2  文本标签收不到数值:VST3 对 CTextLabel 只调 setText ⇒ 改为读标签文本。
 2.3  嵌套控件读值恒为 0(架构性教训)⇒ 视图不再读控件(见第 8 步)。
 2.4  55 度显示成 0.6:RangeParameter::toString 收到的是归一化值 ⇒ 委托基类转换。
 2.5  列表选心形却显示 Figure-8:归一化应除以 (项数 − 1)。
 2.6  NOS 默认变 20 cm、Decca 越界、edited 不出现:一个陈旧重复常量遮蔽了正确的制式数。
 2.7  SRA 从 96 跳到 133:阈值改取该制式自己的标准阵列(取被问的阵列是循环定义)。
 2.8  XY + 八字算出 180 度(表里 76):重合阵列增益和为零 ⇒ 0/0 = NaN ⇒ 现在 75.7 度。
 2.9  超心形与八字的响应为负:被当成小差值 ⇒ 改为「极性相反 = 已越过极值」。
 2.10 点话筒 Angle 行消失:面板改矮而行坐标没动 ⇒ 布局检查增加父容器层级检查。
 2.11 面板中间空洞:条件显示的行从中间移到最后。
 2.12 关窗再开动点回原点:视图缓存了被重建的控件指针 ⇒ 每次刷新重新查找;读数搬到绘制前。
 2.13 厂商名与占位信息 ⇒ Forrest's Plug-ins,UID 未动,旧工程照常加载。

三、验证方式 / How it is verified
------------------------------------------------------------------------
 无头测试(纯头文件独立编译)、契约检查(标签与参数枚举、各视图子控件形状)、
 布局检查(越界、重叠、父容器层级)、Steinberg 验证器 47 项、状态版本链 v1 → v10。
 最强的一次外部验证:模型不知道 Blumlein 是什么,却从「重合 + ±45° + 八字」算出 75.7°,
 与已发表的 76° 相差 0.3°。

 Headless suites on the pure headers; a contract check; a layout check with parent containment;
 the validator's 47 tests; state versions from v1 to v10. The strongest external check: 75.7°
 against a published 76°, derived without being told what a Blumlein pair is.

------------------------------------------------------------------------
四、刻意没有做 / Deliberately not done
------------------------------------------------------------------------
 · 点话筒自身的指向性不再套一遍 —— 它已经录在信号里,再施加一次就是重复计算。
 · AAX(Pro Tools 拒绝未签名的 AAX;需要 Avid 审批 + PACE 签名 + iLok)。
 · macOS / AU(SDK 自带 AU 包装器且不需要签名,只差一台 Mac)。
 · 自动延时测量(互相关 + 几何校验)—— 留待 2.0。

 The spot's own polar pattern is not applied again. AAX needs Avid approval, PACE signing and an
 iLok. AU needs only a Mac. Automatic delay estimation is kept for 2.0.

------------------------------------------------------------------------
五、已知风险 / Known risks
------------------------------------------------------------------------
 · 关闭时间差后,Angle 仍是几何输入:改它会同时改距离、离轴角与参照话筒。
 · 中线处参照话筒切换到另一支,延时有一个 Δt 大小的跳变(手动使用无碍,自动化时会显现)。
 · 单声道折叠下,左右只要存在 Δt 就有梳状零点 f = 1/(2Δt) —— 时间差成像的固有代价。
 · 近距离时乐器不能近似为点声源,几何给出的对齐值只是代表性近似。

 With the time difference off, Angle remains a geometry input. Crossing the centre line switches
 the reference microphone, a step the size of the time difference. Any left/right time difference
 gives mono comb nulls at f = 1/(2Dt). Close to the source the instrument is not a point.
